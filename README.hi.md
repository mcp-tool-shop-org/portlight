पोर्टलाइट एक टर्मिनल के लिए पहले व्यापार पर केंद्रित समुद्री रणनीति गेम है। आप बीस बंदरगाहों में एक कप्तान, एक जहाज और प्रतिष्ठा का प्रबंधन करते हैं। जब आप सामान बेचते हैं, तो कीमतें बदलती हैं। अनुबंधों के लिए उत्पत्ति का प्रमाण आवश्यक है। दलाल और गोदाम यह निर्धारित करते हैं कि किसी यात्रा का मूल्य क्या होगा। चार विजय मार्ग उस करियर को दर्शाते हैं जिसे आपने वास्तव में बनाया है - न कि उस करियर को जिसे आपने पहले दिन चुना था।

**TUI** (`portlight tui`) या **CLI** में खेलें। समान सहेजी गई फ़ाइल। समान दुनिया।

## इंस्टॉल करें

```bash
pip install "portlight[tui]"
```

पायथन 3.11+. `tui` अतिरिक्त टेक्स्टुअल को जोड़ता है। केवल CLI के लिए: `pip install portlight`।

क्या आपके पास पायथन नहीं है? npm लॉन्चर GitHub रिलीज़ बाइनरी प्राप्त करता है:

```bash
npx @mcptoolshop/portlight
```

प्रिंट-एंड-प्ले PDF किट: `pip install "portlight[printandplay]"`।

## खेलें

```bash
portlight tui
```

यदि कोई सहेजी गई फ़ाइल नहीं है, तो TUI स्लॉट और **नया** विकल्प दिखाता है। एक कप्तान प्रकार चुनें। फिर:

| कुंजी | यह क्या करता है |
|-----|----------------|
| **D** | डैशबोर्ड (करियर / मील के पत्थर यहां प्रदर्शित होते हैं) |
| **M / B / S** | बाजार · खरीदें · बेचें |
| **G / A** | यात्रा चयनकर्ता · एक दिन आगे बढ़ाएं |
| **H** | बंदरगाह: प्रावधान, मरम्मत, भर्ती; साथ ही काम, बर्खास्त, शिकार। समुद्र में, H शिकार करता है। |
| **K** | अनुबंध। स्वीकार करने या त्यागने के लिए **K को फिर से दबाएं**। |
| **W** | बुनियादी ढांचा। पट्टे पर लेने, जमा करने, निकालने, एक दलाल खोलने, एक लाइसेंस खरीदने या क्रेडिट प्राप्त करने के लिए **W को फिर से दबाएं**। |
| **P** | बंदरगाह। जहाज निर्माण यार्ड के लिए **P को फिर से दबाएं** (जहाज का ढांचा खरीदें, अपग्रेड करें, डॉक में रखें)। |
| **F** | बेड़ा। एक पुरस्कार जहाज पर सवार होने, डॉक में रखने, स्थानांतरित करने या बेचने के लिए **F को फिर से दबाएं**। |
| **V** | विश्व मानचित्र |
| **?** | सहायता |

CLI टाइप किए गए कमांड के साथ समान गेम है:

```bash
portlight new "Captain Hawk" --type merchant
portlight market
portlight buy grain 10
portlight sail al_manar
portlight advance
portlight sell grain 10
portlight tui
```

`portlight --json status` एक स्थिर डिक्ट (कप्तान, बंदरगाह, कार्गो, बाजार, मार्ग, बोर्ड) को बिना ANSI के डंप करता है। `portlight saves` स्लॉट की सूची दिखाता है।

निर्देशित पहला सत्र: [docs/START_HERE.md](docs/START_HERE.md)। हैंडबुक: [https://mcp-tool-shop-org.github.io/portlight/handbook/](https://mcp-tool-shop-org.github.io/portlight/handbook/)।

## पोर्टलाइट क्यों?

अधिकांश व्यापार गेम व्यापार को एक संख्या में समेट देते हैं जो बढ़ती है। पोर्टलाइट व्यापार को एक वाणिज्यिक अनुशासन के रूप में मानता है:

- **कीमतें आपके व्यापार पर प्रतिक्रिया करती हैं।** अनाज डंप करें और स्थानीय कीमत गिर जाएगी।
- **बंदरगाहों की अपनी आर्थिक पहचान होती है।** पोर्टो नोवो अनाज उगाता है। सिल्क हेवन रेशम का निर्यात करता है। यह संरचना है, शोर नहीं।
- **यात्राओं में जोखिम होता है।** तूफान, समुद्री डाकू, निरीक्षण, मौसम। प्रावधान, जहाज और चालक दल वास्तविक लागत हैं।
- **अनुबंधों के लिए प्रमाण की आवश्यकता होती है।** सही सामान, सही बंदरगाह, ट्रैक की गई उत्पत्ति, वास्तविक समय सीमा।
- **बुनियादी ढांचे से समय बदलता है।** गोदाम कार्गो को व्यवस्थित करते हैं। दलाल बोर्ड में सुधार करते हैं। लाइसेंस प्रीमियम पहुंच खोलते हैं। सभी पांच क्षेत्रों में दलाल कार्यालय और एक क्षेत्रीय चार्टर है।
- **प्रतिष्ठा चार अक्षों पर आधारित है।** वाणिज्यिक विश्वास, सीमा शुल्क की सख्ती, क्षेत्रीय स्थिति, अंडरवर्ल्ड। वे स्वतंत्र रूप से दरवाजे खोलते और बंद करते हैं।
- **गेम आपके द्वारा बनाए गए को पढ़ता है।** मील के पत्थर और चार विजय मार्ग साक्ष्य को दर्शाते हैं, न कि एक मेनू विकल्प को।

## दुनिया

पांच क्षेत्र। बीस बंदरगाह। तैतीस मार्ग।

| क्षेत्र | बंदरगाह | चरित्र |
|--------|-------|-----------|
| **Mediterranean** | पोर्टो नोवो, अल-मनार, सिल्वा बे, समुद्री डाकू का विश्राम स्थल | अनाज, लकड़ी, मसाले। सुरक्षित शुरुआती जल। |
| **North Atlantic** | आयरनहेवन, स्टॉर्मवॉल, थॉर्नपोर्ट | लोहा, हथियार, गार्नीजन व्यापार। सख्त निरीक्षण। |
| **West Africa** | सन हार्बर, पाम कोव, आयरन पॉइंट, पर्ल शैलो | कपास, रम, मोती। सस्ते प्रावधान। |
| **East Indies** | जेड पोर्ट, मानसून रीच, सिल्क हेवन, क्रॉसविंड आइल, ड्रैगन गेट, स्पाइस नैरोज़ | रेशम, मसाले, चीनी मिट्टी के बर्तन, चाय। उच्चतम लाभ। मानसून का जोखिम। |
| **South Seas** | एम्बर आइल, टाइफून एंकरेज, कोरल थ्रोन | मोती, दवाएं। दूरस्थ अंतिम खेल के जल। |

अठारह सामान (जिसमें खाल और तस्करी शामिल है)। एक सौ चौंतीस नामित NPC। आठ सक्रिय नामित कप्तानों के साथ चार समुद्री डाकू गुट। मौसमी मौसम। त्यौहार, अंधविश्वास, चालक दल का मनोबल।

`portlight new "Name"` बिना `--type` के रोस्टर खोलता है। बाउंटी हंटर केवल एक स्वाद लेबल नहीं है: `portlight bounty accept <id>` फिर `portlight bounty hunt <id>` नामित कप्तान को मजबूर करता है। भूत आईडी चली गई; बोर्ड केवल सक्रिय `PIRATE_CAPTAINS` की सूची दिखाता है।

## सिस्टम

**अर्थव्यवस्था** - दुर्लभता मूल्य निर्धारण, बाढ़ दंड, बाजार झटके, क्षेत्रीय आयात/निर्यात पहचान।

**यात्राएं** - बहु-दिवसीय यात्रा। मौसम, समुद्री डाकू, निरीक्षण। नामित समुद्री डाकू द्वंद्वयुद्ध तब पसंद करते हैं जब एक सक्रिय बाउंटी उस जल क्षेत्र से मेल खाती है।

**अनुबंध** - सात परिवार, चौबीस टेम्पलेट। विश्वास और स्थिति द्वार। उत्पत्ति-सत्यापित वितरण।

**प्रतिष्ठा** - क्षेत्रीय स्थिति, वाणिज्यिक विश्वास, सीमा शुल्क की सख्ती, अंडरवर्ल्ड कनेक्शन। वे स्वतंत्र रूप से दरवाजे खोलते और बंद करते हैं।

**युद्ध** — व्यक्तिगत मुद्रा त्रिकोण (झटका / वार / बचाव), हाथापाई और लंबी दूरी की लड़ाई, लड़ने की शैलियाँ (टीयूआई **वाई** शैली की विशेष क्षमता को सक्रिय करता है)। नौसेना: पार्श्व हमला, निकट, बचाव, हमला, पलायन। वास्तविक बेड़े के ढांचे के साथ पुरस्कार प्राप्त करें।

**बुनियादी ढांचा** — तीन गोदाम स्तर। दलाल कार्यालय: सभी पाँच क्षेत्रों में स्थानीय + स्थापित। सात लाइसेंस (उत्तरी अटलांटिक और दक्षिणी समुद्र सहित पाँच क्षेत्रीय अधिकार, साथ ही दो वैश्विक)। वास्तविक रखरखाव।

**वित्त** — ढांचा, माल और अनुबंध-गारंटी बीमा। ब्याज और चूक के साथ तीन क्रेडिट स्तर।

**बेड़ा** — कई ढांचे, एक ही बंदरगाह पर डॉक/बोर्ड, माल का स्थानांतरण, अठारह उन्नयन।

**करियर** — सत्ताइस मील के पत्थर, सात प्रोफ़ाइल टैग, चार विजय मार्ग। डैशबोर्ड खाता दिखाता है; दैनिक प्रगति के साथ पूरी की गई उपलब्धियाँ।

## विजय मार्ग

- **कानूनी व्यापार गृह** — उच्च विश्वास, प्रीमियम अनुबंध, स्वच्छ प्रतिष्ठा, बुनियादी ढांचे की व्यापकता।
- **छाया नेटवर्क** — दबाव में विलासिता का लाभ, जब्त होने से बचा, अभी भी आगे।
- **महासागरीय पहुंच** — पूर्वी इंडीज की प्रतिष्ठा, दूरस्थ बुनियादी ढांचा, लंबी दूरी की महारत।
- **वाणिज्यिक साम्राज्य** — बहु-क्षेत्रीय गोदाम, दलाल, लाइसेंस, वित्तीय लाभ।
